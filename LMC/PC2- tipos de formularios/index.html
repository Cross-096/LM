Elementos de un formulario web

HTML ofrece diferentes tipos de controles de formularios para que los usuarios puedan introducir, seleccionar y enviar informacion. aqui tienes todos los tipos principales de ejemplos:

Campo de texto

Permite escribir una linae de texto <input type ="text">

Clave

texto oculto por seguridad <input type ="password">

Correo electronico

Para direcciones de Email <input type ="Email">

Numero

permite introducir numeros <input type="number">

Telefono

Para numeros de telefono <input type="tel">

URL

Para direcciones web <input type="url">

Busqueda

campo de busqueda <input type="search">

Fecha (decadas)

numero de decada <input type="numero">

Fecha

selector de fecha <input type="date">

Hora

selector de hora <input type="time">

Semana

selector de semana <input type="week">

Color

selector de color <input type="color">

Rango

selector de rango <input type="range">

Archivo

selector de archivo <input type="file">

Check-box

permite una unica seleccion <input type="checkbox">

Radio

multiples opciones <input type="radio">

lista desplegable

multiples opciones <input type="select">

lista desplegable multiples respuestas

multiples opciones <option>multiple"</option>

texto varias lineas

texto varias lineas <textarea>

data list

sugerencias al escribir (lista de datos) <input list="(nombre datalist)">

Archivo

adjunta un archivo <input type="file">
